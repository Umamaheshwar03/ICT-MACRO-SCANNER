## ❓ FAQ

**Q: Will this make money?**
A: This is a statistical edge scanner, not a guarantee. The data shows 72% macro-origin rate historically. Always backtest, risk-manage, and never trust past performance.

**Q: Do I need API keys?**
A: No, for public data (CCXT spot market data). For trading, you'd need broker integration.

**Q: Can I modify it?**
A: Yes! Everything in `config.py` is tunable. See examples in `EXAMPLES.md`.

**Q: How do I integrate with my broker?**
A: Export signals to JSON and use your broker's API. See `scanner/live_scanner.py`.

**Q: Is this production-ready?**
A: For scanning/backtesting, yes. For live trading, add broker integration and risk controls.

## 📞 Support

### If Something Doesn't Work

1. **Check logs**: `cat logs/scanner.log`
2. **Read troubleshooting**: See `GETTING_STARTED.md`
3. **Try test scan**: `python main.py --single-scan`
4. **Verify setup**: `pip list | grep ccxt`

### Common Issues

| Problem | Solution |
|---------|----------|
| "No module named ccxt" | `pip install ccxt` |
| "Insufficient data" | Market may be sleeping, try BTC/USDT |
| "Connection timeout" | Check internet, try again |
| "Confidence too low" | Lower `MIN_CONFIDENCE_SCORE` in config |
